# 产品群面模拟教练 · PM Group Interview

一个用于产品经理无领导小组讨论的中文 Skill。练习的不只是“我能想出方案”，还包括如何承接别人、处理分歧、作出取舍、推动团队完成交付。

适合产品／AI 产品群面、群面思考路径训练、考前学习和讨论复盘。它不是企业官方题库，也不是预测录用结果的评分器。

## 能做什么

- **先题后答**：先给题目，让你独立思考，不提前泄露解法。
- **虚拟组员交锋**：模拟甲、乙、丙的不同关注点，不把每轮都变成单人面试。
- **陪练模式**：每轮反馈有效贡献、关键缺口和可选改写，再推进一个挑战。
- **全真模式**：讨论中不点评，汇报后统一复盘。
- **信息约束**：支持不能向面试官补信息的群面，未知事项作为假设处理。
- **阶段评分**：内容判断与协作表现分别观察，不因抢到 Leader、说出术语而加分。
- **学习地图**：树状框架、题型分流、协作表达与指标口径。

无需 API Key、服务器或额外插件。组员由同一助手扮演，不是独立模型评审。文字练习不能完整复现真实抢话、语气和现场时间压力。

## 安装到 Codex

需要已安装 Git。在终端运行：

```bash
git clone https://github.com/xiaoruixsss/pm-group-interview.git "$HOME/.codex/skills/pm-group-interview"
```

如果目标文件夹已经存在，不要覆盖，先检查是不是已有安装。安装后在新会话中调用 `$pm-group-interview`；发现方式以你使用的客户端为准。

也可以让支持 Skill 安装的助手从本仓库安装。其他兼容 `SKILL.md` 格式的客户端，可按其文档选择技能目录；本仓库的安装验证以 Codex 为主。

## 一次练习怎么进行

题目与规则 → 独立观点 → 组员交锋 → 方案取舍 → 团队汇报 → 复盘。

用户可以随时说“暂停点评”“只给一个问题”“进入全真模式”“别给答案”“换题”“开始汇报”。用户明确的规则优先于默认设置。

默认轮次压缩，不把聊天等待时间当作实际面试时间；需要严格计时时请自行设倒计时。组员提出的新增约束会标明是模拟设定。

## 原创练习题

| ID | 方向 | 核心训练 |
| --- | --- | --- |
| PGI-01 | 社区首次有价值的发布 | 创作者激活、用户分层、提效与增量 |
| PGI-02 | 平台商业化取舍 | 付费价值、经济性、体验护栏 |
| PGI-03 | AI 团队协作 | 任务闭环、数据边界、人机分工 |
| PGI-04 | AI 功能高尝试低留存 | 数据口径、原因假设、验证策略 |

所有练习均为原创模拟，不代表任何公司实际业务数据或官方真题。用户额外提供的题目会按可核验程度单独标注。

## 资料与隐私

方法源于对产品群面经验材料及训练反馈的独立整理。公开仓库不附原帖截图、第三方原题全文、个人简历、面试录音、内部业务资料或真实训练日志。

Skill 不主动写入或上传训练内容，也不包含遥测。使用它的宿主应用仍可能按自己的设置处理会话数据，请自行检查该应用的数据政策。

如果用户要求“真题”，应给出处与可信边界；找不到可靠来源时不将原创题伪装成真题。

## 验证与限制

结构校验与行为抽查分别进行：文件格式通过不代表每个模型都会稳定遵守全部规则。测试方法及实际记录见 [tests/evals.md](tests/evals.md)。

欢迎提交匿名化的失败案例：实际请求、偏离规则的表现和期望行为。不要在 Issue 中上传个人面试录音、联系方式或内部业务资料。
